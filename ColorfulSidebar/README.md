# ColorfulSidebar

Colour icons in the Finder's sidebar, in the sidebar of Open and Save panels,
and in Mail's mailbox sidebar, as in Mac OS X 10.6.

ColorfulSidebar 1.1.2 is by cvz. (Copyright 2012, released under the MIT
License, http://opensource.org/licenses/mit-license.php). This is a MIP port of
its source: CVZCSController.m is the original, building its icon table on first
use instead of when it loads; ColorfulSidebarMail.m (Mail's sidebar) is new.
Resources/SnowLeopardTrashMailbox* are Mac OS X 10.6 Mail's trash icons.
