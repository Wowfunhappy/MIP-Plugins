# GreenFullscreen
Makes the green + button toggle fullscreen in OS X 10.8–9, as it does in OS X 10.10+, and shows Yosemite's full-screen arrows on it instead of the +.

In full screen, the menu bar's blue exit full screen button sits at the left end of the menu bar, before the Apple menu, instead of at the right end.

With apologies to all of the people who liked the old zoom button... as far as I'm concerned, this was the only good thing Apple changed in Yosemite. The old behavior never made any sense.

This MIP plugin backports the Yosemite behavior to Mavericks. This is particularly useful if you frequently switch between older Macs and newer ones.
